# DIY扩音器：混龄50分钟课件

适用一至四年级混龄班。

- DIY-Amplifier-50min.pptx：23页可编辑PPT，含教师备注。
- DIY-Amplifier-Preview.pdf：课件预览。
- Teacher-Guide.docx：教师指南。
- Student-Worksheet.pdf：可打印观察单。

在GitHub打开文件后，点击 Download raw file（下载原始文件）。PPT下载后用WPS或PowerPoint打开。

本课件使用用户提供的组装照片，修改了课堂流程及不适用于该装置的电子扩音器解释。上课前须以实际教具试装试音。
